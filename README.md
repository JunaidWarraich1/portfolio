# Muhammad Junaid Warraich — Developer Portfolio

Production personal portfolio website engineered with **React 18**, **Vite**, and **Tailwind CSS**. Showcases production architectures, fintech invariants, and real cloud systems.

## Features
- **Midnight Sapphire & Emerald Aurora Theme:** Modern glassmorphism, responsive canvas background, and crisp typography.
- **Top 5 Production Systems:**
  1. **WorkFlow Pro:** Full-stack SaaS marketplace (React 18 + FastAPI + Neon Cloud PostgreSQL 17).
  2. **Fintech Wallet System:** Double-entry ledger microservice with row-level locks and idempotency keys.
  3. **EquiLedger:** Hamilton/Hare-Niemeyer largest-remainder quota math engine.
  4. **Grand Bank ATM:** Dynamic backtracking note dispenser with 10/10 passing unit tests.
  5. **Library Management System:** Production circulation engine live on Vercel.
- **Interactive Terminal:** Real-time inspection of backend and algorithmic source snippets.
- **1-Click ATS Resume Download:** Direct printable ATS-optimized resume.
- **Zero Fluff:** Strictly production-grade design and architecture.
